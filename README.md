# Text Analysis Using Python

## Project Information
- **Internship:** Artificial Intelligence and Machine Learning (AI & ML)
- **Organization:** Veda Technology
- **Task:** Level 1 – Day 6
- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook

## Description
Text Analysis is a beginner-level Python project that analyzes a given paragraph and calculates the total number of words, characters, vowels, and repeated words.

## Objectives
- Calculate the total number of words in a text.
- Count the total number of characters, including spaces and punctuation.
- Count the vowels (a, e, i, o, u).
- Identify repeated words and their frequencies.
- Understand basic text processing techniques used in Natural Language Processing (NLP).

## Features
- Accepts text input from the user.
- Calculates word and character counts.
- Counts vowels in the given text.
- Identifies repeated words and displays their frequencies.
- Displays the analysis results in a structured format.

## Python Concepts Used
- Strings and string methods
- User input using `input()`
- Lists and dictionaries
- Loops and conditional statements
- Functions from the `collections` module
- Text preprocessing
- Word frequency analysis

## Libraries Used
- `collections.Counter`
- `string`

Both modules are included in Python's standard library, so no additional installation is required.

## How to Run
1. Open the project in Jupyter Notebook.
2. Run the code cell.
3. Enter a paragraph when prompted.
4. View the word count, character count, vowel count, and repeated-word analysis.

## Sample Input
Python is easy to learn. Python is useful for AI.

## Expected Output
- **Word Count:** 10
- **Character Count:** 49
- **Vowel Count:** 17
- **Repeated Words:**
  - python: 2 times
  - is: 2 times

*Note: Character count includes spaces and punctuation. Word count excludes surrounding punctuation.*

The Text Analysis project demonstrates basic text processing using Python. It provides practical experience in analyzing text, counting word frequencies, and understanding concepts that form the foundation of Natural Language Processing.
